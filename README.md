# Geospatial API

A Node.js + Express API that fetches geospatial weather data from OpenWeatherMap and stores it in MongoDB.

## Tech Stack

- Node.js
- Express
- MongoDB + Mongoose
- OpenWeatherMap API
- dotenv

## Setup

1. Clone the repo
2. Run `npm install`
3. Create a `.env` file in the project root with:
   - `MONGODB_URI` - the uri to your
